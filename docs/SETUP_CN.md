# 手机配置教程（Octop 后端版）

本教程适用于**已安装本项目 Octop 版固件**的 ESP-Mosaico 裸机。全部配置都在这台设备自己的网页里完成：选 Wi-Fi、填密码、填 Octop 地址与账号，保存即重启。**不需要手机 App，不需要配对，不需要任何语音服务 Key。**尚未安装固件请先看 [项目首页的安装步骤](../README.md#直接安装)。

**操作顺序：连接设备热点 → 打开 192.168.4.1 → 扫描并选择 Wi-Fi、填密码 → 填 Octop 地址与账号 → 保存并重启 → 按住顶部 AI 键说话。**

> `docs/assets/setup/` 里的截图来自上一版（Muse + 千问朗读）固件，页面字段和本教程不一致，仅作历史参考；本版本不再朗读，也不再连接 Muse。

## 开始前准备

- 已刷好 Octop 版固件、电量充足的设备（不需要摄像头或扩展插件）。
- 一个可访问的自托管 **Octop**：形如 `http://192.168.1.20:8088` 的地址，以及它的**用户名和密码**。Octop 侧的 ASR（MiMo）与智能体由部署者自己配好，设备只管调用。
- 常用 Wi-Fi 名称和密码。扫描会同时列出 2.4 GHz 与 5 GHz 网络，但请选设备长期使用时信号最好的那个；混合频段名称相同的网络以实际连上为准。
- 一台能连 Wi-Fi 的手机，浏览器即可，不装任何 App。

**建议先在能上网的网络下确认 Octop 地址和账号可用（能登录它的控制台），复制好备用，再连设备热点。**设备热点只提供本地配置页，不能用来访问外网。

| 网络 | 用途 |
| --- | --- |
| `Mochi-Setup-XXXX` | 手机访问设备配置后台，无密码，仅首次或手动进入时开启 |
| 家中或办公室常用 Wi-Fi | 设备长期访问 Octop，需要该网络密码 |

## 1. 手机连接设备热点

设备首次开机、尚未保存配置时，会自动开启 **`Mochi-Setup-XXXX`** 热点（末尾两个字符因设备而异）。已经配置过的设备，用 **齿轮 → 手机配置** 重新打开热点。

打开手机 **设置 → Wi-Fi**，选择这个热点，**无需密码**。提示"不安全的网络"是因为热点没设密码，"无互联网连接"不影响本地配置；手机问是否继续使用时选择保持连接。

## 2. 浏览器打开 192.168.4.1

在 Safari 或 Chrome 的**地址栏**（不是搜索框）输入：

```text
http://192.168.4.1
```

必须是 `http://`，不要改成 `https://`。页面标题是「首次配置 / First-time setup」，右上角按钮可在 **中文 / English** 之间切换，字段名随语言变化，顺序不变。

## 3. Wi-Fi：扫描、选择、填密码

页面第一个区块是 **Wi-Fi**。点开就会自动扫描附近网络，结果出现在下拉框里，括号中是信号强度（RSSI，越接近 0 越强）。没扫到就点 **扫描** 重试，或把手机拿近一些。

在下拉里选中设备要长期使用的网络，再填 **密码（开放网络留空）**。

这一步不能跳过：设备保存前会**真的用这个密码连一次**（最长约 15 秒），连不上就提示「那个网络连不上，请确认密码后重试」，并且**不会写入任何配置**，所以不会出现"保存成功但重启后哑掉"的情况。

## 4. Octop 服务：地址、用户名、密码

第二个区块是 **Octop 服务**。

| 页面字段 | 应填写的值 |
| --- | --- |
| Octop 地址 / Octop URL | 你自己的部署，例如 `http://192.168.1.20:8088`；支持 `https://` 与端口、子路径前缀 |
| 用户名 / Username | Octop 账号名，不能有空格 |
| 密码 / Password | 该账号的密码，可以含空格 |

地址必须以 `http://` 或 `https://` 开头，不能含空格、`@` 或 `#`（这三者会改变 URL 的解析方式）。填写时可以先勾选 **显示密钥** 核对，保存前取消勾选即可隐藏。

## 5. 语音识别（可留空）

第三个区块是**可选**的识别服务覆盖，用途是绕开 Octop 自带的 MiMo ASR：

| 页面字段 | 说明 |
| --- | --- |
| 自定义识别接口 / Custom STT endpoint | 完整地址，需接受 `multipart` 上传（字段名 `audio`）并返回 `{"text":"…"}` |
| 自定义识别 token / Custom STT token | 该接口的 `Authorization: Bearer <值>`；没有就留空 |

**两个框都留空即可**——设备会直接调用 `POST <Octop 地址>/api/voice/stt`，识别与对话共用同一个账号。只有确实要换识别引擎时才填这里。

## 6. 保存并重启

点 **「保存并重启 / Save and restart」**，页面会显示「正在连接 Wi-Fi 并保存配置（约 15 秒）…」，成功后提示「已保存，设备正在重启。请切回常用 Wi-Fi。」

约两秒后设备重启，热点随之关闭，手机断开该热点属正常现象。把手机切回常用 Wi-Fi 即可，后续不需要再打开配置页。

凭据保存在设备的 NVS 分区里（明文，未启用 NVS 加密），**不会回显**：下次进配置页需要重新完整填写，请自行保管。

## 7. 第一次对话

设备重启后进入主界面：

- 左上角状态应显示 **「Octop 在线」**（未就绪时显示「正在连接」或「服务未就绪」）。
- **按住顶部红色 AI 键**说话，松开即发送。设备只做一件事：录音 → 交给 Octop 识别 → 把智能体的回答**显示在屏幕上**。
- 回答是流式上屏的：**第一段文字一到，设备就切到阅读页**并开始排页，页脚提示「正在接收回答…」；文字收完后才开始自动翻页。
- 松开按键到回答开始之间有两个不同提示：先「正在把你的话转成文字…」（Octop 侧识别），再「思考中」（智能体在写回答）。
- **设备不会发声，也没有喇叭相关设置**。这一版把朗读整条链路删掉了，屏幕是唯一的输出通道。

## 8. 长回答与阅读页

回答只显示在**阅读页**：顶部小头像 + 标题「Octop 的回答」+ 页码，正文一块 444×300 的"纸"，20 px 字号排 **10 行 × 22 个汉字 = 每页 220 字**（拉丁字母按实际宽度排，会更密一些）。500 字的回答三页读完。

- 轻触正文 → 下一页；到最后一页再轻触 → 回主界面。
- 在正文上**左右横滑**（滑动 ≥64 px 且横向占优）也可翻页；滑动手势会吞掉紧随其后的那一次点击，所以一次手势只翻一页。
- **长按正文**或点「回首页」→ 立刻回主界面。
- 页脚提示会说明当前状态：「正在接收回答…」「自动翻页 N 秒 · 轻触抢先」「轻触下一页 · 长按回首页」「读完轻触返回」。
- 收完文字后按「翻页间隔」（3–15 秒，默认 7 秒）自动往下翻，翻到最后一页自动停止；手动翻一次即切到手动。
- **按住 AI 键可以打断**正在接收的回答，直接开始新一轮提问。
- 正在阅读时屏幕不会进入"困倦"表情，但仍会按设定时间熄屏；轻触屏幕、拿起设备或按键都能唤醒，熄屏期间不会自动翻页。

## 9. 常用设置

点右上角齿轮进入 **伙伴设置**：

| 设置项 | 操作与作用 |
| --- | --- |
| 拾音 | 麦克风增益（0–100%，默认 55%）。这一版没有音量输出，滑条改为录音灵敏度；离设备远或声音小就调高 |
| 亮度 | 拖动即预览，松手写入；熄屏时会先渐暗再黑屏 |
| 语言 | 点击在 中文 / English 之间切换，界面文案与识别语言提示一起变 |
| 自动熄屏 | 滑块可选 5、10、15、20、30、60 秒 |
| 翻页 | 3–15 秒，默认 7 秒 |
| 手机配置 / Phone setup | 重新开启配置热点，用于更换 Wi-Fi 或 Octop 账号 |

设置页最下面一行是链路状态，形如 **「Wi-Fi 已连接 · Octop 就绪」**，异常时会带上具体原因（例如「正在登录」「没有可用智能体」「无法建立会话」），排错先看这一行。

轻触角色会触发开心动画；拿起或晃动设备会唤醒屏幕。

## 以后如何修改配置

在设备上点 **齿轮 → 手机配置 / Phone setup**。设备会保存一个"下次开机进入配置模式"的标记并重启，重启后热点重新打开。手机连上 `http://192.168.4.1`，把 Wi-Fi 和 Octop 信息**完整重填一遍**并保存。

- 这个入口不会擦掉旧凭据；只要没有成功提交新表单，旧配置依然生效。
- 提交新配置会同时替换 Wi-Fi 与 Octop 三项，并丢弃旧的会话线程（下一次提问会重新创建一个）。
- 若只想换 Wi-Fi，也要把 Octop 地址与账号一并填对，否则保存会被格式校验拒绝。

## 常见问题

**看不到热点**：首次未配置时自动开启；已配置的设备需先点「手机配置」。确认设备已开机并完成重启，必要时拔插电源重来。

**192.168.4.1 打不开**：确认手机仍连着设备热点（很多手机会自动切回常用 Wi-Fi），在地址栏输入完整 `http://192.168.4.1`，必要时临时关闭 VPN。

**提示「请完整填写必填项」**：地址必须 `http://` / `https://` 开头且不含空格、`@`、`#`；用户名不能有空格；Wi-Fi 必须先选中一项。

**提示「那个网络连不上」**：密码错误、网络隐藏或信号太弱。确认密码后重试，配置不会被保存。

**左上角一直「服务未就绪」/ 设置页显示「Octop 不可达」**：按顺序检查——设备所在 Wi-Fi 是否真能上网、Octop 服务是否在跑（浏览器直接开一次那个地址）、地址是否带错端口或子路径、账号密码是否正确。改对之后重进一次「手机配置」提交即可。

**提示「没有可用智能体」或「无法建立会话」**：Octop 账号能登录但没有可用的 agent，或它无法创建会话线程。到 Octop 侧确认至少有一个运行中的智能体。

**提示「等了 45 秒没有回答」**：Octop 首包确实可能很慢（长上下文时实测过 13 秒以上），设备给 45 秒首字窗口和 60 秒 token 空闲窗口。重问一次，或让 Octop 侧的提示词更短。

**提示「语音识别失败」/「没有听清」**：按住后没有真正说话、离麦克风太远（把「拾音」调高），或 Octop 的 ASR 未配置好。设备端不做识别，只看它返回的 `text`。

**屏幕有文字但没有声音**：这是本版本的设计，不是故障。设备没有喇叭输出，也没有静音开关。

**回答只显示了一部分**：一条回答最多上屏约 4 KB（约 1300 个汉字），后面的内容不会显示；Octop 侧的总缓冲是 64 KiB，超出部分会以「…」标记截断。让 Octop 少写一点，或者分段提问。
